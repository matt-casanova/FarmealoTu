## Scope

App Android completa (todas las pantallas de `ui/screens/`): Inicio, 5 preguntas, Resultado, 01 Comparar,
Detalle de estrategia, 02 Ventajas y desventajas, 03 Riesgos, 04 Incertidumbre, Explorar mi zona, Datos de terreno,
Fuentes y límites, Conexión.

## Visitor mode

Operate. El agricultor completa una tarea: responder 5 preguntas, comparar rotaciones y entender riesgos e
incertidumbre. Claridad, consistencia y lo nativo de Android (Material 3) por encima de la expresión.

## Work type

Refinamiento, no rediseño: se conserva la identidad de DESIGN.md, la navegación, las funciones y el texto factual.

6El prototipo físico (pequeño): nodo de campo de 3 zonas

Tres macetas pequeñas con el mismo sustrato y distinta humedad, que representan tres zonas de un campo. En cada una hay un sensor de humedad y una sonda de temperatura enterrados; afuera, un pequeño mástil con BME680, DHT11 y LDR. Un ESP32 envía todo por Wi-Fi a la pestaña «Datos de terreno». El mensaje que transmite: un campo no es uniforme, y un píxel satelital de 9–50 km lo promedia todo.

Reglas eléctricas
  • Las señales analógicas van solo a ADC1 (GPIO 32–39). El ADC2 deja de funcionar con el Wi-Fi activo. GPIO 27 se usa como pin digital, así que no tiene problema.
  • Hay que promediar 64 lecturas por sensor y usar analogReadMilliVolts().
  • Todo va a 3.3 V. Medir la polaridad con el multímetro antes de energizar.
  • Correr un I2C scanner para saber si el BME680 está en 0x76 o 0x77.
  • Anotar la dirección de 64 bits de cada DS18B20 para rotular T1, T2 y T3.
  • Algunos clones del sensor capacitivo v1.2 tienen fallas de fábrica: probar cada unidad y guardar el repuesto.
  • El consumo lo domina el ESP32 con Wi-Fi. Un power bank común alcanza para la noche, pero hay que llevar uno de repuesto y desactivar el autoapagado si lo tiene.

6.6 Calibración (obligatoria: sin ella, los números no significan nada)

Humedad: método gravimétrico de 3 puntos por sensor

  1. Para cada sensor, en tres estados (seco, medio y saturado), se registra el promedio de lecturas raw.
  2. Se toma una muestra de 20–30 g de sustrato junto al sensor y se pesa húmeda (mh).
  3. Se seca en microondas en ciclos de 1 min, pesando entre ciclos, hasta peso constante (ms). Sin recipientes metálicos y sin quemar la muestra.
  4. θg = (mh − ms) / ms. Para pasar a volumétrica: θv = θg · ρb/ρw, con ρb = masa seca / volumen de una muestra tomada con un recipiente de volumen conocido.
  5. Se ajusta la curva raw → θv de cada sensor por separado (lineal por tramos con los 3 puntos) y las constantes se cargan en calibration.h.
  6. Se reporta el error del ajuste, aclarando que con 3 puntos el error es orientativo.

Temperatura: desfase de los DS18B20

  1. Las 3 sondas en el mismo vaso de agua a temperatura ambiente, durante 5 min.
  2. Si hay un termómetro de referencia, se registra junto a ellas.
  3. Desfasei = Ti − mediana(T1, T2, T3) (o − Tref). Si supera 0.5 °C, se anota y se corrige en el firmware.

Plan B

Sin microondas o sin tiempo: calibración relativa de 2 puntos (aire y agua) con la insignia «humedad relativa (sin calibración gravimétrica)». Nunca se muestra como «% volumétrico».

  • No se compara la maceta con SMAP de forma cuantitativa: un RMSE así no tendría sentido.
